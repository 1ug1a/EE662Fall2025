# EE662Fall2025

WsnLab.py is a simulation library in Python based on WsnSimPy for self-organized networks.
See [wsnlab/midterm_2.py](wsnlab/midterm_2.py) for my edited code, and see [final paper data and graphs.xlsx](https://github.com/1ug1a/EE662Fall2025/blob/main/final%20paper%20data%20and%20graphs.xlsx) for the raw outputs of the PowerShell scripts used to automate my experiments.

# Requirements

You need to install the following packages.
- simpy
